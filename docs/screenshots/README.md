# Screenshots

The main README expects these files (PNG, about 1400px wide):

| File | What to capture |
|---|---|
| `01-input.png` | Home screen with the example picker and request form |
| `02-clarify.png` | Sales-leads example: "Conflicting requirements detected" and the Critical questions |
| `03-traceability.png` | Traceability Matrix tab: the metrics row plus the matrix |
| `04-process.png` | Process Analysis tab: current and future-state diagrams |

Tip: on macOS, press Cmd+Shift+4 then Space to capture a single window.
